## The Theory (The What)

**ProGuard** is a Java [bytecode]({{ "/en/glossary/bytecode/" | relative_url }}) shrinker, optimizer, and obfuscator that was the default tool for Android release builds before [R8]({{ "/en/glossary/r8/" | relative_url }}) replaced it. While R8 is now the active tool, ProGuard's name lives on: the configuration file is still called `proguard-rules.pro`, the Gradle DSL still uses `proguardFiles(...)`, and the keep-rule syntax is the same. Understanding "ProGuard rules" is essential even though R8 is the one executing them.

## The Senior Nuance

- **ProGuard rules are R8 rules**: The `proguard-rules.pro` file in every Android project is read by [R8]({{ "/en/glossary/r8/" | relative_url }}), not ProGuard. The rule syntax is identical. When documentation or error messages say "add a ProGuard rule," they mean "add a rule to `proguard-rules.pro` that R8 will apply."
- **Keep rules protect reflection**: `-keep`, `-keepnames`, `-keepclassmembers` prevent R8 from removing or renaming classes and members that are accessed via [runtime reflection]({{ "/en/glossary/runtime-reflection/" | relative_url }}). Libraries like Gson, Retrofit, and Firebase ship their own rules via `consumer-rules.pro` — these are automatically included in the consuming app.
- **Minimal keep rules are best**: Every `-keep` rule is code that R8 cannot optimize. Senior developers write the narrowest possible rules: keep only the specific classes/members that reflection needs, not entire packages. Over-broad rules bloat the APK and defeat optimization.
- **`-dontwarn` and `-dontnote`**: Suppress warnings for classes R8 can't resolve (typically from optional dependencies). Use judiciously — a suppressed warning might mask a real missing class that will crash at [runtime]({{ "/en/glossary/runtime/" | relative_url }}).
- **Testing release builds**: ProGuard/R8 issues only appear in release builds (`minifyEnabled true`). Senior developers run release builds regularly during development, not just before shipping — discovering a shrinking issue the night before release is avoidable pain.
