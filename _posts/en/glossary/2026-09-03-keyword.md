## The Theory (The What)

A **keyword** is a reserved word with special meaning in the language grammar. Kotlin distinguishes three categories:

- **Hard keywords** (`class`, `fun`, `val`, `var`, `if`, `when`, `return`, `object`, etc.) — cannot be used as identifiers under any circumstance.
- **Soft keywords** (`by`, `get`, `set`, `field`, `import`, `constructor`, etc.) — have special meaning only in specific contexts and can be used as identifiers elsewhere. The `by` [keyword]({{ "/en/01-kotlin-core/delegated-properties/" | relative_url }}) for [delegated properties]({{ "/en/01-kotlin-core/delegated-properties/" | relative_url }}) is a soft keyword: it has special meaning only after a property declaration.
- **Modifier keywords** (`abstract`, `open`, `override`, `private`, `suspend`, `inline`, `data`, `sealed`, etc.) — act as modifiers in declarations but can be used as identifiers in other positions.

At [compile time]({{ "/en/glossary/compile-time/" | relative_url }}), the parser recognizes keywords and applies the language rules they trigger. Some keywords map to [bytecode]({{ "/en/glossary/bytecode/" | relative_url }}) constructs (`class` → class definition, `fun` → method), while others are purely compile-time directives that leave no trace in the output (`inline`, `reified`).

## The Senior Nuance

- A Senior knows that Kotlin's soft keyword design is deliberate: it maximizes backward compatibility with Java codebases. Java identifiers like `object`, `when`, or `by` can be referenced from Kotlin using backtick escaping: `` `object` ``.
- Understanding the hard/soft/modifier distinction helps when reading unfamiliar code: seeing `by` in a property declaration signals delegation, but `by` as a function parameter name is perfectly legal and unrelated.
- The `suspend` modifier keyword is unique: it does not just annotate — it fundamentally changes the function's [bytecode]({{ "/en/glossary/bytecode/" | relative_url }}) signature by adding a `Continuation` parameter, making it one of the most impactful keywords in the language.
