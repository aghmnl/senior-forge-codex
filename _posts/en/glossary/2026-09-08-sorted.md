## The Theory (The What)

**`sorted()`** returns a new [`List`]({{ "/en/glossary/list/" | relative_url }}) with the elements in ascending natural order, requiring `T : Comparable<T>`. `sortedBy { }` sorts by a selector, `sortedWith(comparator)` by an explicit `Comparator`, and `sortedDescending()` reverses the order. All of them copy; the in-place variants on a [`MutableList`]({{ "/en/glossary/mutable-list/" | relative_url }}) are `sort()` and `sortBy { }`.

```kotlin
// From FollowApp Suite — TasksViewModel.kt
val tags = allLabels
    .filter { (label, _) -> label.type == LabelType.TAG }
    .flatMap { (_, options) -> options.map { it.label } }
    .distinct()
    .sorted()

// From FollowApp Suite — TasksViewModel.kt
entry.key.name to entry.value.sortedBy { it.sortOrder }.map { it.label }
```

## The Senior Nuance

- `sorted` is inherently **eager** and buffering: it must see every element before emitting one. A [`Sequence`]({{ "/en/glossary/sequences/" | relative_url }}) chain ending in `sorted` materialises the whole thing, so the laziness bought nothing — the one case where [`asSequence`]({{ "/en/glossary/as-sequence/" | relative_url }}) is measurably pointless.
- It is `O(n log n)` and allocates a full copy plus, for `sortedBy`, one boxed key per comparison unless the selector returns a [primitive]({{ "/en/glossary/primitives/" | relative_url }})-friendly type. Sorting inside a composable re-runs on every recomposition; sort in the [ViewModel]({{ "/en/glossary/viewmodel-store/" | relative_url }}), cached against its inputs.
- Kotlin's sort is **stable**, so chaining `sortedBy { it.name }.sortedBy { it.priority }` produces a correct secondary ordering — at the cost of two full passes. `sortedWith(compareBy({ it.priority }, { it.name }))` does it in one.
- A `Comparator` inconsistent with [`equals`]({{ "/en/glossary/equals/" | relative_url }}) (returning `0` for objects that are not equal) is legal for sorting but breaks any sorted [`Set`]({{ "/en/glossary/sets/" | relative_url }}) or [`Map`]({{ "/en/glossary/maps/" | relative_url }}) built from the same comparator.
