## The Theory (The What)

**`finally`** is the block of a [`try`]({{ "/en/glossary/try-catch/" | relative_url }}) that runs on *every* exit path: normal completion, a caught exception, an uncaught one, and — inside a coroutine — a [`CancellationException`]({{ "/en/glossary/cancellation-exception/" | relative_url }}). That last case makes it the standard place for cleanup that must survive cancellation: resetting a flag, closing a resource, releasing a lock.

```kotlin
// From FollowApp Suite — TasksViewModel.kt
isBulkWriteInFlight = true
try {
    kotlinx.coroutines.coroutineScope {
        ids.forEach { launch { quickCompleteTaskUseCase(taskId = it, isCompleted = isCompleted) } }
    }
} finally {
    isBulkWriteInFlight = false
}
```

## The Senior Nuance

- **You cannot suspend inside it after cancellation — unless you say so.** Once the [`Job`]({{ "/en/glossary/job/" | relative_url }}) is cancelled, any suspend call in `finally` throws immediately. Cleanup that *must* suspend (flushing to disk, sending a "closed" message) needs `withContext(NonCancellable) { }`.
- **Pair it with `coroutineScope` to mean "after all children".** A `finally` after a bare loop of `launch` runs at once; after [`coroutineScope`]({{ "/en/glossary/coroutine-scope-builder/" | relative_url }}) it runs when the last child is done.
- **Do not swallow exceptions in it.** A `return` or a throw inside `finally` replaces the original exception — including the cancellation.
