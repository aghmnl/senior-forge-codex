## The Theory (The What)

**`isActive`** is the `Boolean` that reports whether the current [`Job`]({{ "/en/glossary/job/" | relative_url }}) is still running — `false` once it has been cancelled or completed. It is the *non-throwing* cancellation check, the counterpart of [`ensureActive()`]({{ "/en/glossary/ensure-active/" | relative_url }}): reading it never interrupts anything, so it is the right tool when you need to *branch* on cancellation rather than stop.

```kotlin
// From FollowApp Suite — TasksScreen.kt
try {
    lazyListState.scrollBy(direction * autoScrollStep)
} catch (e: CancellationException) {
    // Preempted by another scroll mutation (e.g. the
    // reorder re-anchor); keep scrolling unless the
    // effect itself was cancelled
    if (!isActive) throw e
}
```

## The Senior Nuance

- **It tells two cancellations apart.** A caught [`CancellationException`]({{ "/en/glossary/cancellation-exception/" | relative_url }}) may come from *your* coroutine being cancelled (`isActive == false` → rethrow) or from an inner operation being preempted while you are still alive (`isActive == true` → continue). That distinction is the only legitimate reason to catch one.
- **In a loop, prefer `while (isActive)` to `while (true)`.** It makes a CPU loop [cooperative]({{ "/en/glossary/cooperative-cancellation/" | relative_url }}) without throwing mid-iteration.
- **It is also on `CoroutineScope`.** Inside a `launch` or `LaunchedEffect` block, bare `isActive` resolves to the enclosing coroutine's job.
- See [Structured Concurrency]({{ "/en/02-coroutines-flow/structured-concurrency/" | relative_url }}).
