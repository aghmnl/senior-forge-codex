## The Theory (The What)

**Retrofit** is Square's type-safe HTTP client for the JVM and Android: you declare an interface with annotated methods (`@GET`, `@POST`, `@Path`, `@Body`) and Retrofit generates the implementation, delegating the actual request to [OkHttp]({{ "/en/glossary/okhttp/" | relative_url }}) and (de)serialising bodies through a converter (Moshi, kotlinx.serialization, Gson). Since 2.6 a method may be declared [`suspend`]({{ "/en/glossary/suspend-functions/" | relative_url }}); the call then runs on OkHttp's [thread pool]({{ "/en/glossary/thread-pool/" | relative_url }}) and resumes the caller with the parsed result — **main-safe without any `withContext`**.

```kotlin
// Not found in FAS — standalone example
interface TasksApi {
    @GET("tasks/{id}")
    suspend fun task(@Path("id") id: String): TaskDto     // main-safe by contract
}
```

## The Senior Nuance

- **A `suspend` Retrofit call is already off Main.** Wrapping it in `withContext(Dispatchers.IO)` is the same double-wrap smell as with [Room]({{ "/en/glossary/room/" | relative_url }}). The IO hop happens inside OkHttp's dispatcher.
- **Errors are exceptions, not `Response` codes — unless you ask.** A `suspend fun` returning the body throws `HttpException` on 4xx/5xx and `IOException` on network failure; returning `Response<T>` puts the status in your hands.
- **Cancellation is wired through.** Cancelling the coroutine cancels the underlying OkHttp `Call`, so a screen leaving mid-request does not leak a socket.
- See [Main-Safety]({{ "/en/02-coroutines-flow/main-safety/" | relative_url }}).
