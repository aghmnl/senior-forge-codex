## The Theory (The What)

**`as`** is Kotlin's explicit, *unsafe* [cast]({{ "/en/glossary/cast/" | relative_url }}) operator: `x as Foo` asserts that `x` is a `Foo` and throws [`ClassCastException`]({{ "/en/glossary/class-cast-exception/" | relative_url }}) at [runtime]({{ "/en/glossary/runtime/" | relative_url }}) if it is not (and a `NullPointerException`-style `TypeCastException` if `x` is null and `Foo` is non-nullable). It is the escape hatch for when the compiler cannot prove the type through a [Smart Casts]({{ "/en/01-kotlin-core/smart-casts/" | relative_url }}) smart cast — a [`var`]({{ "/en/glossary/var/" | relative_url }}) property, a value crossing a module boundary, a generic erased to `Any`. Its non-throwing sibling is [`as?`]({{ "/en/glossary/as-safe-cast/" | relative_url }}).

```kotlin
// Not found in FAS — standalone example
val fragment = supportFragmentManager.findFragmentByTag(TAG) as DetailFragment
// Throws ClassCastException if the fragment under TAG is not a DetailFragment.
// Acceptable only when that would be a programming error, never a runtime possibility.
```

## The Senior Nuance

- **`as` is a claim, and a crash is how the compiler audits it.** Reserve it for cases where a wrong type is *impossible by construction* — you just created the object, or the API contract fixes the type. If the type is genuinely uncertain, use `as?` or an [`is`]({{ "/en/glossary/is-operator/" | relative_url }}) check.
- **Every `as` that follows an `is` is redundant.** `if (x is Foo) (x as Foo).bar` is what Java forces you to write; in Kotlin the smart cast already did it. The redundant cast is a signal the author did not trust the compiler.
- **Generics erase.** `list as List<String>` cannot be checked at runtime (unchecked cast warning); it will "succeed" and fail later on the first element. Prefer `List<*>` plus element checks, or `reified` helpers.
- See [Smart Casts]({{ "/en/01-kotlin-core/smart-casts/" | relative_url }}).
