## The Theory (The What)

A **contract** is a declaration inside a function body — `contract { returns() implies (value != null) }` — that tells the compiler something about the function's behaviour it could not infer on its own: that a lambda is called exactly once, or that if the function returns normally a condition holds. The stdlib uses contracts in [`require`]({{ "/en/glossary/require/" | relative_url }}), [`check`]({{ "/en/glossary/check/" | relative_url }}), [`requireNotNull`]({{ "/en/glossary/require-not-null/" | relative_url }}) and [`checkNotNull`]({{ "/en/glossary/check-not-null/" | relative_url }}), which is why the compiler applies a [Smart Casts]({{ "/en/01-kotlin-core/smart-casts/" | relative_url }}) smart cast after calling them. Contracts on user code are still `@ExperimentalContracts`.

```kotlin
// Not found in FAS — standalone example
@OptIn(ExperimentalContracts::class)
fun isValidId(id: String?): Boolean {
    contract { returns(true) implies (id != null) }
    return !id.isNullOrBlank()
}

fun load(id: String?) {
    if (isValidId(id)) {
        println(id.length)   // smart cast to String: the contract promised id != null
    }
}
```

## The Senior Nuance

- **Contracts are how a plain function participates in smart casting.** Without one, the compiler sees an opaque call and forgets everything it knew; with one, `requireNotNull(x)` is as good as `if (x == null) throw`.
- **The compiler trusts the contract; it does not verify it.** A contract that lies (`returns(true) implies (id != null)` when the body can return `true` for null) produces a smart cast that crashes with a [`NullPointerException`]({{ "/en/glossary/null-pointer-exception/" | relative_url }}) at [runtime]({{ "/en/glossary/runtime/" | relative_url }}). Keep contracts trivially true.
- **`callsInPlace` is the other half.** It lets a `val` be initialised inside a lambda (`run { x = 1 }`) because the compiler knows the lambda runs exactly once.
