## The Theory (The What)

**`combine`** is an intermediate [`Flow`]({{ "/en/glossary/flow/" | relative_url }}) operator that merges several flows into one: every time **any** source emits, it runs the transform with the **latest** value of each and emits the result. It waits for all sources to have produced at least one value before the first emission. Like every intermediate operator it is lazy — combining flows executes nothing until the result is collected.

```kotlin
// From FollowApp Suite — PremiumUseCases.kt
operator fun invoke(): Flow<Boolean> = combine(
    premiumLedgerRepository.getLedger(),
    authRepository.getSession()
) { ledger, session ->
    PremiumLifecycle.isPremium(now = System.currentTimeMillis(), premiumUntil = ledger.premiumUntil, isSignedIn = session != null)
}
```

## The Senior Nuance

- **`combine` is "latest of each", `zip` is "pair them up".** `zip` waits for one value from *each* side per emission; `combine` re-emits on every change of any side. Using `zip` for UI state stalls the screen the moment one source stops emitting.
- **One silent source blocks the first emission.** If any input never emits, the combined flow never emits either — a common cause of a screen stuck on Loading. Give each source an initial value.
- **It is still [cold]({{ "/en/glossary/cold-stream/" | relative_url }}).** Combining three flows and collecting twice runs all three producers twice.
