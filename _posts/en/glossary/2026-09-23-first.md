## The Theory (The What)

**`first()`** is a [terminal operator]({{ "/en/glossary/terminal-operations/" | relative_url }}) that suspends until the flow's first emission, returns that value and **cancels the producer**. It turns a stream into a single value — a snapshot of a live source — so the calling [suspend function]({{ "/en/glossary/suspend-functions/" | relative_url }}) completes instead of observing forever. `first { predicate }` waits for the first value that matches, and `firstOrNull()` returns `null` on an empty flow instead of throwing `NoSuchElementException`.

```kotlin
// From FollowApp Suite — CleanUpPresetsUseCase.kt
// One-shot read of a live source: take the current presets, act, finish
suspend fun onLabelDeleted(labelName: String) {
    val presets = presetRepository.getAll().first()
    presets.forEach { preset -> /* ... */ }
}
```

## The Senior Nuance

- **It is the right tool for a snapshot and the wrong one for observation.** `first()` where you meant [`collect`]({{ "/en/glossary/collect/" | relative_url }}) gives correct data once and then goes stale in silence — no error, no log.
- **On an empty flow it throws.** `first()` raises `NoSuchElementException` if the flow completes without emitting; use `firstOrNull()` when emptiness is legitimate.
- **Cancelling the producer is the point.** On a [Room]({{ "/en/glossary/room/" | relative_url }})-backed flow, `first()` reads once and tears down the observer instead of leaving a live query behind.
