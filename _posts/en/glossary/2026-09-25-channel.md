## The Theory (The What)

A **`Channel<T>`** is a communication primitive between [coroutines]({{ "/en/glossary/coroutines/" | relative_url }}): one side calls [`send`]({{ "/en/glossary/send/" | relative_url }}), the other calls [`receive`]({{ "/en/glossary/receive/" | relative_url }}), and **each value is delivered to exactly one receiver**. Its capacity decides when [`send`]({{ "/en/glossary/send/" | relative_url }}) suspends: [`RENDEZVOUS`]({{ "/en/glossary/channel-capacity/" | relative_url }}) (the default, no buffer: sender and receiver meet), [`BUFFERED`]({{ "/en/glossary/channel-capacity/" | relative_url }}), [`UNLIMITED`]({{ "/en/glossary/channel-capacity/" | relative_url }}), or [`CONFLATED`]({{ "/en/glossary/channel-capacity/" | relative_url }}) (keeps only the latest). A channel is a [hot stream]({{ "/en/glossary/hot-stream/" | relative_url }}): values sent into it wait there whether or not anyone is receiving yet. It can be exposed as a [Flow]({{ "/en/glossary/flow/" | relative_url }}) with [`receiveAsFlow()`]({{ "/en/glossary/receive-as-flow/" | relative_url }}).

```kotlin
// Not found in FAS — standalone example
private val _events = Channel<UiEvent>(Channel.BUFFERED)
val events: Flow<UiEvent> = _events.receiveAsFlow()

fun onSaved() {
    _events.trySend(UiEvent.ShowSaved)   // waits in the buffer until the UI collects
}
```

## The Senior Nuance

- **Queue, not broadcast.** With two collectors on [`receiveAsFlow()`]({{ "/en/glossary/receive-as-flow/" | relative_url }}), each event goes to only one of them. That is the opposite of [SharedFlow]({{ "/en/glossary/sharedflow/" | relative_url }}), where every collector gets every value.
- **Buffered events survive a missing collector.** An event sent while the screen is rotating waits in the buffer and is delivered when the UI collects again — the reason channels are a common choice for one-shot UI events. It is not bulletproof: an event taken out of the channel can still be lost if the collector is cancelled before handling it.
- **[`send`]({{ "/en/glossary/send/" | relative_url }}) vs [`trySend`]({{ "/en/glossary/try-send/" | relative_url }}).** [`send`]({{ "/en/glossary/send/" | relative_url }}) suspends when the buffer is full; [`trySend`]({{ "/en/glossary/try-send/" | relative_url }}) returns immediately with a result that says whether the value was accepted. Channels also have to be closed; a `Flow` does not.
