## The Theory (The What)

**Kotlin** is a statically typed programming language created by JetBrains. It compiles to [bytecode]({{ "/en/glossary/bytecode/" | relative_url }}) for the [JVM]({{ "/en/glossary/jvm/" | relative_url }}) (and from there to Android's DEX format), and also to JavaScript, native binaries and WebAssembly. Since 2019 Google has declared Android development **Kotlin-first**: new Jetpack libraries, [Jetpack Compose]({{ "/en/glossary/jetpack-compose/" | relative_url }}) and [coroutines]({{ "/en/glossary/coroutines/" | relative_url }}) are designed for it.

```kotlin
// Not found in FAS — standalone example
// Null safety, data classes and coroutines: three reasons Android adopted it
data class Task(val id: String, val title: String, val dueAt: Long?)

suspend fun overdue(repo: TaskRepository, now: Long): List<Task> =
    repo.getAll().filter { task -> task.dueAt?.let { it < now } ?: false }
```

## The Senior Nuance

- **100% interoperable with Java.** Kotlin calls Java and Java calls Kotlin in the same project, which is what allowed Android codebases to migrate one file at a time. The seams show up in [platform types]({{ "/en/glossary/platform-types/" | relative_url }}) and annotations like [@JvmStatic]({{ "/en/glossary/jvm-static/" | relative_url }}).
- **Its safety is enforced by the compiler.** Nullability in the type system, exhaustive `when` over [sealed classes]({{ "/en/glossary/sealed-class/" | relative_url }}), and read-only collections catch whole classes of bugs before runtime.
- **Many of its features are compiler work, not runtime magic.** Data classes, extension functions, [inline functions]({{ "/en/glossary/inline-functions/" | relative_url }}) and suspend functions all compile down to ordinary JVM bytecode — which is why understanding what they compile to is a Senior-level topic.
