## The Theory (The What)

**`LiveData<T>`** is the observable data holder from Android Architecture Components that predates [Flow]({{ "/en/glossary/flow/" | relative_url }}). It is **[lifecycle-aware]({{ "/en/glossary/lifecycle-aware/" | relative_url }}) by itself**: `observe(owner, observer)` only delivers values while the owner is `STARTED` or `RESUMED`, and removes the observer automatically when the owner is `DESTROYED`. `MutableLiveData` exposes `setValue` (main thread) and `postValue` (any thread). It is the ancestor of the `_uiState` / `uiState` pattern that [StateFlow]({{ "/en/glossary/stateflow/" | relative_url }}) took over.

```kotlin
// Not found in FAS — standalone example
class LegacyViewModel : ViewModel() {
    private val _count = MutableLiveData(0)
    val count: LiveData<Int> = _count

    fun increment() {
        _count.value = (_count.value ?: 0) + 1   // main thread only
    }
}

// In a Fragment: stops delivering in the background, unsubscribes on destroy
viewModel.count.observe(viewLifecycleOwner) { render(it) }
```

## The Senior Nuance

- **No equality filter.** Every `setValue` notifies observers, even with an equal value. [StateFlow]({{ "/en/glossary/stateflow/" | relative_url }}) drops equal writes. Code migrated from LiveData that relied on repeated notifications stops working silently.
- **`postValue` coalesces.** Several `postValue` calls before the main thread runs deliver only the last one — a form of [conflation]({{ "/en/glossary/conflation/" | relative_url }}) that surprises people who expected every value.
- **Nullable and optional initial value.** `value` can be `null` before anything is set, which pushes null checks into the UI. `StateFlow` forces a real initial value.
- **Why new code prefers StateFlow.** LiveData is Android-only, has a tiny operator set, and ties lifecycle to the holder. With `StateFlow` the holder is plain [Kotlin]({{ "/en/glossary/kotlin/" | relative_url }}) and lifecycle awareness moves to the collector ([repeatOnLifecycle]({{ "/en/glossary/repeat-on-lifecycle/" | relative_url }}), [collectAsStateWithLifecycle]({{ "/en/glossary/collect-as-state-with-lifecycle/" | relative_url }})). LiveData is still worth knowing: most legacy codebases use it.
