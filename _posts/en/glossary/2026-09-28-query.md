## The Theory (The What)

A **query** is a request to a database to read (or change) data. On Android it is usually SQL executed by [Room]({{ "/en/glossary/room/" | relative_url }}): each method of a [DAO]({{ "/en/glossary/dao/" | relative_url }}) annotated with `@Query` carries the SQL it runs. When the method returns a [Flow]({{ "/en/glossary/flow/" | relative_url }}), the query is **observable**: Room runs it again every time the table it reads from changes, and emits the new result.

```kotlin
// From FollowApp Suite — LabelOptionDao.kt
// An observable query: it re-runs and emits whenever label_options changes
@Query("SELECT * FROM label_options ORDER BY sort_order ASC, label ASC")
fun getAllOptionsStream(): Flow<List<LabelOptionEntity>>
```

## The Senior Nuance

- **An observable query costs per collector.** Because a `Flow` from Room is a [cold stream]({{ "/en/glossary/cold-stream/" | relative_url }}), each [collector]({{ "/en/glossary/collector/" | relative_url }}) runs its own query and its own observer. Several screens collecting the same one multiply the work, unless it is shared with [shareIn]({{ "/en/glossary/share-in/" | relative_url }}) or [stateIn]({{ "/en/glossary/state-in/" | relative_url }}).
- **Sort and filter in SQL when possible.** The database does it faster and with less memory than sorting a list in Kotlin, especially with an index on the sorted column.
- Room checks the SQL at compile time: a typo in a column name is a build error, not a crash.
