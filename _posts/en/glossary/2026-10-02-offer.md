## The Theory (The What)

**`offer(value)`** is the old, **deprecated** non-suspending way to put a value into a [Channel]({{ "/en/glossary/channel/" | relative_url }}). It returned `true` or `false` depending on whether the value fit, but it **threw an exception** when the channel was [closed]({{ "/en/glossary/close/" | relative_url }}), which made it unsafe to call from callbacks. It was replaced by [trySend]({{ "/en/glossary/try-send/" | relative_url }}), which reports every outcome, including a closed channel, in a [ChannelResult]({{ "/en/glossary/channel-result/" | relative_url }}) without throwing.

```kotlin
// Not found in FAS — standalone example
// Old code
if (!channel.offer(event)) Log.w(TAG, "Dropped")    // throws if the channel is closed

// Replacement
channel.trySend(event).onFailure { Log.w(TAG, "Dropped") }   // never throws
```

## The Senior Nuance

- **It shows up in older code and answers.** Recognizing it matters when reading legacy code or old examples; new code uses `trySend`.
