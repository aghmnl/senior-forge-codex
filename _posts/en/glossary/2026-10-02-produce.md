## The Theory (The What)

**`produce { }`** is a coroutine builder that creates a [Channel]({{ "/en/glossary/channel/" | relative_url }}), launches a coroutine that fills it with [send]({{ "/en/glossary/send/" | relative_url }}), and returns the receiving side (`ReceiveChannel`). When the producer coroutine finishes, fails or is cancelled, the channel is **closed automatically**, so whoever is reading it with a `for` loop stops cleanly. It is marked as an experimental API, but it is the idiomatic way to build a producer.

```kotlin
// Not found in FAS — standalone example
fun CoroutineScope.numbers(): ReceiveChannel<Int> = produce {
    for (n in 1..3) send(n)
}                                  // the channel closes when the block ends

for (n in scope.numbers()) println(n)   // 1, 2, 3, then the loop ends
```

## The Senior Nuance

- **It removes the most common channel bug.** A channel created by hand has to be closed by someone, or its receivers wait forever. With `produce`, closing is tied to the producer coroutine and cannot be forgotten.
- **It lives in a scope.** `produce` is an extension on `CoroutineScope`, so cancelling that scope cancels the producer and closes the channel.
