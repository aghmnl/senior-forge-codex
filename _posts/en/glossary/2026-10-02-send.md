## The Theory (The What)

**`send(value)`** puts a value into a [Channel]({{ "/en/glossary/channel/" | relative_url }}). It is a [suspend function]({{ "/en/glossary/suspend-functions/" | relative_url }}): when the channel has no room (it is full, or it is a rendezvous channel with no buffer and nobody receiving), `send` **suspends** until a receiver takes a value and makes room. Sending to a channel that was already [closed]({{ "/en/glossary/close/" | relative_url }}) throws an exception.

```kotlin
// Not found in FAS — standalone example
val channel = Channel<Int>()       // rendezvous: no buffer

launch { channel.send(1) }         // suspends here until someone receives
launch { println(channel.receive()) }   // takes the 1 and lets send continue
```

## The Senior Nuance

- **Suspending is how a channel applies backpressure.** A fast producer waits for a slow consumer instead of filling memory.
- **From code that cannot suspend, use [trySend]({{ "/en/glossary/try-send/" | relative_url }}).** It returns immediately and says whether the value was accepted.
- See [trySend() vs send()]({{ "/en/02-coroutines-flow/trysend-vs-send/" | relative_url }}).
