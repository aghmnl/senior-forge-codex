## The Theory (The What)

**`conflate()`** is a [`Flow`]({{ "/en/glossary/flow/" | relative_url }}) operator that lets a slow [collector]({{ "/en/glossary/collector/" | relative_url }}) skip intermediate values: the [upstream]({{ "/en/glossary/upstream/" | relative_url }}) keeps running, and when the [collector]({{ "/en/glossary/collector/" | relative_url }}) is ready it gets **only the latest value**. It is the same as `buffer(Channel.CONFLATED)`.

```kotlin
// Not found in FAS — standalone example
sensorReadings()
    .conflate()                     // a slow UI only sees the newest reading
    .collect { render(it) }
```

## The Senior Nuance

- **Right when only the latest matters** (location, sensors, progress), wrong when every value must be processed.
- **On a [`callbackFlow`]({{ "/en/glossary/callback-flow/" | relative_url }}) it also prevents [`trySend`]({{ "/en/glossary/try-send/" | relative_url }}) from failing** for a full buffer: the new value replaces the pending one.
- **Not to confuse with `collectLatest`**, which cancels the work on the previous value instead of skipping values.
