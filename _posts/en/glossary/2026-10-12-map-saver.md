## The Theory (The What)

**`mapSaver`** builds a [`Saver`]({{ "/en/glossary/saver/" | relative_url }}) that stores a value as a **map** of named saveable values. `save` returns the map, and `restore` reads each field by its key.

```kotlin
// Not found in FAS — standalone example
val FilterSaver = mapSaver(
    save = { mapOf("query" to it.query, "onlyPending" to it.onlyPending) },
    restore = { Filter(it["query"] as String, it["onlyPending"] as Boolean) }
)
```

## The Senior Nuance

- **Named keys make it robust to reordering** and easier to read than [`listSaver`]({{ "/en/glossary/list-saver/" | relative_url }}) for classes with several fields, at the cost of casts in `restore`.
- See [remember & rememberSaveable]({{ "/en/03-jetpack-compose/remember-remembersaveable/" | relative_url }}).
