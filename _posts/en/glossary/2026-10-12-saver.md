## The Theory (The What)

A **`Saver<Original, Saveable>`** tells [`rememberSaveable`]({{ "/en/glossary/remember-saveable/" | relative_url }}) how to store a type that a [`Bundle`]({{ "/en/glossary/bundle/" | relative_url }}) cannot hold. It has two functions: `save` converts the value into something saveable ([primitives]({{ "/en/glossary/primitives/" | relative_url }}), strings, lists of them), and `restore` rebuilds the value from it. It is passed as `saver`, or as `stateSaver` when the remembered value is a [`MutableState`]({{ "/en/glossary/mutable-state/" | relative_url }}).

```kotlin
// Not found in FAS — standalone example
val ColorSaver = Saver<Color, Long>(
    save = { it.value.toLong() },
    restore = { Color(it.toULong()) }
)
```

## The Senior Nuance

- **Prefer [`@Parcelize`]({{ "/en/glossary/parcelize/" | relative_url }}) for your own classes** when the class can be [`Parcelable`]({{ "/en/glossary/parcelable/" | relative_url }}); a `Saver` fits types you do not control, such as a third-party class.
- **[`listSaver`]({{ "/en/glossary/list-saver/" | relative_url }}) and [`mapSaver`]({{ "/en/glossary/map-saver/" | relative_url }})** are shortcuts for the common case of breaking a value into several saveable parts.
- See [remember & rememberSaveable]({{ "/en/03-jetpack-compose/remember-remembersaveable/" | relative_url }}).
