## The Theory (The What)

**`Checkbox(checked, onCheckedChange)`** is Material's checkbox composable. Like every Material input it is [stateless]({{ "/en/glossary/stateful-stateless/" | relative_url }}): it draws `checked` and reports a tap through `onCheckedChange`, and the caller decides the new value. Passing `onCheckedChange = null` makes it display-only, which is useful when the whole row handles the click.

```kotlin
// Not found in FAS — standalone example
Checkbox(checked = task.isCompleted, onCheckedChange = { onToggle(task.id, it) })
```

## The Senior Nuance

- **The caller can refuse the change** simply by not updating the state, which is how validation or confirmation dialogs fit in.
