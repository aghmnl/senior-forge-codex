## The Theory (The What)

A **Preview** is a composable annotated with `@Preview` that Android Studio renders in the editor without running the app. It shows a component with sample data, and can render several configurations at once (dark mode, font sizes, screen sizes).

```kotlin
// Not found in FAS — standalone example
@Preview
@Composable
fun RatingBarPreview() { RatingBar(rating = 3, onRatingChange = {}) }
```

## The Senior Nuance

- **[Stateless]({{ "/en/glossary/stateful-stateless/" | relative_url }}) composables are trivial to preview**: pass values and empty [lambdas]({{ "/en/glossary/lambdas/" | relative_url }}). A composable that needs a [ViewModel]({{ "/en/glossary/viewmodel/" | relative_url }}) cannot be previewed without building one, which is a strong hint that it should receive state instead.
- **Previews are also the base of screenshot tests**, which catch visual regressions automatically.
