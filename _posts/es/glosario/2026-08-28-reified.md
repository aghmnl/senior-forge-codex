## The Theory (El Qué)

**`reified`** es un modificador de Kotlin para parámetros de tipo de [funciones inline]({{ "/es/glosario/inline-functions/" | relative_url }}) que hace que el argumento de tipo esté disponible en [tiempo de ejecución]({{ "/es/glosario/runtime/" | relative_url }}). Normalmente, la [JVM]({{ "/es/glosario/jvm/" | relative_url }}) borra los parámetros de tipo genérico durante el [tiempo de compilación]({{ "/es/glosario/compile-time/" | relative_url }}) — `List<String>` se convierte simplemente en `List` en el [bytecode]({{ "/es/glosario/bytecode/" | relative_url }}). Con `reified`, el compilador sustituye el tipo real en cada sitio de llamada (porque la función es `inline`), por lo que operaciones como `is T`, `T::class` y `filterIsInstance<T>()` funcionan como si el tipo fuera conocido.

## The Senior Nuance (El Matiz Senior)

- `reified` solo funciona con funciones `inline` porque el mecanismo es sustitución en tiempo de compilación: el compilador reemplaza `T` con el tipo concreto en cada sitio de llamada antes de generar bytecode. No hay reflexión en runtime involucrada — es un truco de compile-time que produce bytecode específico para el tipo.
- Sin `reified`, necesitarías pasar un parámetro `KClass<T>` explícitamente: `fun <T : Any> parse(json: String, clazz: KClass<T>)`. Con `reified`, la llamada se convierte en `parse<MyData>(json)` — API más limpia, misma seguridad.
- Casos de uso comunes: `Gson().fromJson<T>(json)` (type token para deserialización), `intent.getParcelableExtra<T>(key)` (extras de Android), `startActivity<T>()` (helpers de navegación) y `filterIsInstance<T>()` (filtrado de colecciones).
- Como `reified` inserta el tipo en cada sitio de llamada, **no podés** llamar a una función `reified` desde Java — Java no tiene concepto de funciones inline. Esto es un trade-off: API de Kotlin más limpia a costa de interop con Java.
- `reified` no funciona con funciones no-inline, parámetros de tipo a nivel de clase, ni funciones `suspend` (ya que la suspensión de coroutines rompe el contrato de inlining).

```kotlin
// Not found in FAS — standalone example
inline fun <reified T : Activity> Context.startActivity(extras: Bundle? = null) {
    val intent = Intent(this, T::class.java)  // T::class funciona porque T es reified
    extras?.let { intent.putExtras(it) }
    startActivity(intent)
}

// Uso — el compilador sustituye SettingsActivity por T en este sitio de llamada
context.startActivity<SettingsActivity>()
```
