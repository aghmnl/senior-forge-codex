## The Theory (El Qué)

Un **Raw Type** (tipo crudo) es una clase genérica de Java usada sin su type argument — `List` en vez de `List<String>`. Los raw types existen solo por compatibilidad hacia atrás con el Java pre-generics (anterior a Java 5), y **Kotlin no tiene ninguno**: el lenguaje nunca te deja omitir el type argument.

```java
// Java — legal, y peligroso
List raw = new ArrayList<String>();
raw.add(42);                      // solo un unchecked warning
String s = (String) raw.get(0);   // ClassCastException en runtime
```

El reemplazo de Kotlin es la [Star Projection]({{ "/es/glosario/star-projection/" | relative_url }}):

```kotlin
// Not found in FAS — standalone example
fun sizeOf(list: List<*>): Int = list.size   // se lee sin problema
// list.add(42)                              // no compila
```

## The Senior Nuance (El Matiz Senior)

- **Los raw types borran la memoria del compilador; `<*>` no.** Con un raw type el compilador olvida que alguna vez hubo un type argument y permite escrituras sin chequear, difiriendo la falla a una [`ClassCastException`]({{ "/es/glosario/class-cast-exception/" | relative_url }}) en algún lugar sin relación. Con la [Star Projection]({{ "/es/glosario/star-projection/" | relative_url }}) el compilador sigue sabiendo que existe algún tipo concreto y simplemente prohíbe las operaciones que necesitarían conocerlo.
- **Igual llegan a Kotlin por interop con Java.** Un método de librería Java que devuelve un `List` raw aparece en Kotlin como *platform type* (`List<!>`), que suprime tanto el chequeo de nullability como el de type argument. Un Senior anota o envuelve esto en el límite, en vez de dejar que un platform type se propague hacia la [Data Layer]({{ "/es/glosario/data-layer/" | relative_url }}).
- **Los raw types son consecuencia del [Type Erasure]({{ "/es/glosario/type-erasure/" | relative_url }}), no su causa.** El erasure es lo que hace que puedan existir en [Runtime]({{ "/es/glosario/runtime/" | relative_url }}); la decisión de Java de seguir aceptándolos en [Compile Time]({{ "/es/glosario/compile-time/" | relative_url }}) es la elección de compatibilidad separada y deliberada que Kotlin decidió no repetir.
- **Los warnings de "unchecked cast" son la forma moderna del mismo riesgo.** `value as List<String>` en Kotlin compila con un warning precisamente porque el erasure lo vuelve inverificable. Tratá ese warning como un error en review: es un raw type con otro nombre.
