## The Theory (El Qué)

**`put(key, value)`** inserta o reemplaza una entrada en un [`MutableMap`]({{ "/es/glosario/mutable-map/" | relative_url }}) y devuelve el valor *anterior* de esa clave, o `null`. El [Syntax Sugar]({{ "/es/glosario/syntax-sugar/" | relative_url }}) de asignación indexada `map[key] = value` compila exactamente a esta llamada, descartando el retorno.

```kotlin
// De FollowApp Suite — GetLabelReferenceCounts.kt
refCounts[label] = (refCounts[label] ?: 0) + 1   // compila a put(...)
```

## The Senior Nuance (El Matiz Senior)

- El valor de retorno descartado es un chequeo gratis de "¿esta clave ya estaba?". `if (index.put(id, row) != null) { /* duplicado */ }` cuesta una búsqueda donde `containsKey` más `put` cuesta dos.
- `getOrPut(key) { default }` es el acumulador idiomático: computa el default solo si hay miss. Ojo: no es atómico y trata un `null` almacenado como miss — una trampa real para un `MutableMap<K, V?>`.
- Una clave cuyo `hashCode` cambia después de insertarla queda inalcanzable: `put` la archivó en un bucket y las búsquedas ahora miran otro. Las claves de un map deben ser [inmutables]({{ "/es/glosario/immutability/" | relative_url }}) — `String` o una [Data Class]({{ "/es/01-kotlin-core/data-classes/" | relative_url }}) tipo valor.
