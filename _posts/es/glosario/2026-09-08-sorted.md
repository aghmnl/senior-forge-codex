## The Theory (El Qué)

**`sorted()`** devuelve un [`List`]({{ "/es/glosario/list/" | relative_url }}) nuevo con los elementos en orden natural ascendente, y requiere `T : Comparable<T>`. `sortedBy { }` ordena por un selector, `sortedWith(comparator)` por un `Comparator` explícito, y `sortedDescending()` invierte el orden. Todos copian; las variantes in-place sobre un [`MutableList`]({{ "/es/glosario/mutable-list/" | relative_url }}) son `sort()` y `sortBy { }`.

```kotlin
// De FollowApp Suite — TasksViewModel.kt
val tags = allLabels
    .filter { (label, _) -> label.type == LabelType.TAG }
    .flatMap { (_, options) -> options.map { it.label } }
    .distinct()
    .sorted()

// De FollowApp Suite — TasksViewModel.kt
entry.key.name to entry.value.sortedBy { it.sortOrder }.map { it.label }
```

## The Senior Nuance (El Matiz Senior)

- `sorted` es inherentemente **eager** y bufferea: necesita ver todos los elementos antes de emitir uno. Una cadena de [Sequences]({{ "/es/glosario/sequences/" | relative_url }}) que termina en `sorted` materializa todo, así que la lazyness no aportó nada — el caso donde [`asSequence`]({{ "/es/glosario/as-sequence/" | relative_url }}) es demostrablemente inútil.
- Es `O(n log n)` y asigna una copia completa más, en `sortedBy`, una clave boxeada por comparación salvo que el selector devuelva un tipo amigable a [Primitives]({{ "/es/glosario/primitives/" | relative_url }}). Ordenar dentro de un composable se re-ejecuta en cada recomposición; ordená en el [ViewModel]({{ "/es/glosario/viewmodel-store/" | relative_url }}), cacheado contra sus inputs.
- El sort de Kotlin es **estable**, así que encadenar `sortedBy { it.name }.sortedBy { it.priority }` produce un orden secundario correcto — al costo de dos pasadas completas. `sortedWith(compareBy({ it.priority }, { it.name }))` lo hace en una.
- Un `Comparator` inconsistente con [`equals`]({{ "/es/glosario/equals/" | relative_url }}) (que devuelve `0` para objetos que no son iguales) es legal para ordenar, pero rompe cualquier [`Set`]({{ "/es/glosario/sets/" | relative_url }}) o [`Map`]({{ "/es/glosario/maps/" | relative_url }}) ordenado construido con ese mismo comparator.
