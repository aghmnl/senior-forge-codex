## The Theory (El Qué)

**`async { }`** es el coroutine builder que arranca una coroutine hija y devuelve un [`Deferred<T>`]({{ "/es/glosario/deferred/" | relative_url }}) — un [`Job`]({{ "/es/glosario/job/" | relative_url }}) que además lleva un resultado. Como [`launch`]({{ "/es/glosario/launch/" | relative_url }}), cuelga la coroutine nueva del [`Job`]({{ "/es/glosario/job/" | relative_url }}) del [`CoroutineScope`]({{ "/es/glosario/coroutine-scope/" | relative_url }}) sobre el que se llama, así que es completamente estructurado: cancelar al padre lo cancela, y el padre lo espera. A diferencia de `launch`, el valor de su bloque se recupera con [`await()`]({{ "/es/glosario/await/" | relative_url }}).

```kotlin
// Not found in FAS — standalone example
suspend fun loadDashboard(): Dashboard = coroutineScope {
    val header = async { api.header() }
    val items = async { api.items() }
    Dashboard(header.await(), items.await())
}
```

## The Senior Nuance (El Matiz Senior)

- **Su fallo tiene dos caminos.** Una excepción en un bloque `async` queda guardada en el [`Deferred`]({{ "/es/glosario/deferred/" | relative_url }}) y se relanza en [`await()`]({{ "/es/glosario/await/" | relative_url }}) — *y* hace fallar al [`Job`]({{ "/es/glosario/job/" | relative_url }}) padre de inmediato, salvo que ese padre sea un supervisor. Por eso dentro de un [`coroutineScope`]({{ "/es/glosario/coroutine-scope-builder/" | relative_url }}) común un `try/catch` alrededor de `await()` no puede salvar al hermano: para entonces ya está cancelado. La recuperación por hijo necesita [`supervisorScope`]({{ "/es/glosario/supervisor-scope/" | relative_url }}).
- **`async` es para valores; `launch` es para efectos.** Un `async` cuyo resultado nadie espera es un `launch` con una excepción escondida.
- **Arrancá los dos, después esperá los dos.** `async { a() }.await(); async { b() }.await()` es secuencial.
