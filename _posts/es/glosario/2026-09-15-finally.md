## The Theory (El Qué)

**`finally`** es el bloque de un [`try`]({{ "/es/glosario/try-catch/" | relative_url }}) que corre en *todo* camino de salida: completitud normal, una excepción atrapada, una no atrapada, y — dentro de una coroutine — una [`CancellationException`]({{ "/es/glosario/cancellation-exception/" | relative_url }}). Ese último caso lo convierte en el lugar estándar para limpieza que debe sobrevivir a la cancelación: resetear una bandera, cerrar un recurso, liberar un lock.

```kotlin
// From FollowApp Suite — TasksViewModel.kt
isBulkWriteInFlight = true
try {
    kotlinx.coroutines.coroutineScope {
        ids.forEach { launch { quickCompleteTaskUseCase(taskId = it, isCompleted = isCompleted) } }
    }
} finally {
    isBulkWriteInFlight = false
}
```

## The Senior Nuance (El Matiz Senior)

- **No podés suspender adentro después de la cancelación — salvo que lo digas.** Una vez cancelado el [`Job`]({{ "/es/glosario/job/" | relative_url }}), cualquier llamada suspend en `finally` lanza de inmediato. La limpieza que *necesita* suspender (volcar a disco, mandar un mensaje de "cerrado") requiere `withContext(NonCancellable) { }`.
- **Combinalo con `coroutineScope` para decir "después de todos los hijos".** Un `finally` tras un loop pelado de `launch` corre al instante; tras [`coroutineScope`]({{ "/es/glosario/coroutine-scope-builder/" | relative_url }}) corre cuando terminó el último hijo.
- **No te tragues excepciones adentro.** Un `return` o un throw dentro de `finally` reemplaza la excepción original — incluida la cancelación.
