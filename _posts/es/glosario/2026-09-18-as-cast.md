## The Theory (El Qué)

**`as`** es el operador de [cast]({{ "/es/glosario/cast/" | relative_url }}) explícito e *inseguro* de Kotlin: `x as Foo` afirma que `x` es un `Foo` y lanza [`ClassCastException`]({{ "/es/glosario/class-cast-exception/" | relative_url }}) en [runtime]({{ "/es/glosario/runtime/" | relative_url }}) si no lo es (y una `TypeCastException`, del estilo de `NullPointerException`, si `x` es null y `Foo` no es nullable). Es la vía de escape para cuando el compilador no puede probar el tipo mediante un smart cast ([Smart Casts]({{ "/es/01-kotlin-core/smart-casts/" | relative_url }})) — una propiedad [`var`]({{ "/es/glosario/var/" | relative_url }}), un valor que cruza un límite de módulo, un genérico borrado a `Any`. Su hermano que no lanza es [`as?`]({{ "/es/glosario/as-safe-cast/" | relative_url }}).

```kotlin
// Not found in FAS — standalone example
val fragment = supportFragmentManager.findFragmentByTag(TAG) as DetailFragment
// Lanza ClassCastException si el fragment bajo TAG no es un DetailFragment.
// Aceptable solo cuando eso sería un error de programación, nunca una posibilidad en runtime.
```

## The Senior Nuance (El Matiz Senior)

- **`as` es una afirmación, y el crash es cómo el compilador la audita.** Reservalo para casos donde un tipo incorrecto es *imposible por construcción* — acabás de crear el objeto, o el contrato de la API fija el tipo. Si el tipo es genuinamente incierto, usá `as?` o un chequeo [`is`]({{ "/es/glosario/is-operator/" | relative_url }}).
- **Todo `as` que sigue a un `is` es redundante.** `if (x is Foo) (x as Foo).bar` es lo que Java te obliga a escribir; en Kotlin el smart cast ya lo hizo. El cast redundante es señal de que el autor no confió en el compilador.
- **Los genéricos se borran.** `list as List<String>` no puede verificarse en runtime (warning de unchecked cast); va a "funcionar" y fallar después con el primer elemento. Preferí `List<*>` más chequeos por elemento, o helpers `reified`.
- Ver [Smart Casts]({{ "/es/01-kotlin-core/smart-casts/" | relative_url }}).
