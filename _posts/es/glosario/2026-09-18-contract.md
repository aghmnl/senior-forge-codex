## The Theory (El Qué)

Un **contract** es una declaración dentro del cuerpo de una función — `contract { returns() implies (value != null) }` — que le dice al compilador algo sobre el comportamiento de la función que no podría inferir solo: que una lambda se llama exactamente una vez, o que si la función retorna normalmente se cumple una condición. La stdlib usa contracts en [`require`]({{ "/es/glosario/require/" | relative_url }}), [`check`]({{ "/es/glosario/check/" | relative_url }}), [`requireNotNull`]({{ "/es/glosario/require-not-null/" | relative_url }}) y [`checkNotNull`]({{ "/es/glosario/check-not-null/" | relative_url }}), y por eso el compilador aplica un smart cast ([Smart Casts]({{ "/es/01-kotlin-core/smart-casts/" | relative_url }})) después de llamarlas. Los contracts en código propio siguen siendo `@ExperimentalContracts`.

```kotlin
// Not found in FAS — standalone example
@OptIn(ExperimentalContracts::class)
fun isValidId(id: String?): Boolean {
    contract { returns(true) implies (id != null) }
    return !id.isNullOrBlank()
}

fun load(id: String?) {
    if (isValidId(id)) {
        println(id.length)   // smart cast a String: el contract prometió id != null
    }
}
```

## The Senior Nuance (El Matiz Senior)

- **Los contracts son la forma en que una función común participa del smart casting.** Sin uno, el compilador ve una llamada opaca y olvida todo lo que sabía; con uno, `requireNotNull(x)` vale tanto como `if (x == null) throw`.
- **El compilador confía en el contract; no lo verifica.** Un contract que miente (`returns(true) implies (id != null)` cuando el cuerpo puede devolver `true` para null) produce un smart cast que crashea con [`NullPointerException`]({{ "/es/glosario/null-pointer-exception/" | relative_url }}) en [runtime]({{ "/es/glosario/runtime/" | relative_url }}). Mantené los contracts trivialmente verdaderos.
- **`callsInPlace` es la otra mitad.** Permite inicializar un `val` dentro de una lambda (`run { x = 1 }`) porque el compilador sabe que la lambda corre exactamente una vez.
