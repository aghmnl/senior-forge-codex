## The Theory (El Qué)

**`var`** declara una referencia mutable que puede reasignarse cualquier cantidad de veces. Una propiedad `var` tiene [getter]({{ "/es/glosario/getter/" | relative_url }}) y setter. Como su valor puede cambiar entre dos lecturas — desde otro [thread]({{ "/es/glosario/thread/" | relative_url }}), un [callback]({{ "/es/glosario/callbacks/" | relative_url }}) o un setter con efectos secundarios — el compilador trata a una propiedad `var` como *inestable* y se niega a hacerle smart cast ([Smart Casts]({{ "/es/01-kotlin-core/smart-casts/" | relative_url }})) después de un chequeo [`is`]({{ "/es/glosario/is-operator/" | relative_url }}) o de null. Una `var` local sí puede smart-castearse mientras no sea capturada y modificada en una lambda.

```kotlin
// Not found in FAS — standalone example
class Repo {
    var cache: Any? = null

    // No compila: `cache` es una propiedad var y podría cambiar después del chequeo
    // fun size() = if (cache is List<*>) cache.size else 0

    // Arreglo idiomático: capturar en un val local, y el smart cast aplica
    fun size(): Int {
        val snapshot = cache
        return if (snapshot is List<*>) snapshot.size else 0
    }
}
```

## The Senior Nuance (El Matiz Senior)

- **El rechazo es una garantía de seguridad, no una limitación del compilador.** Si el compilador smart-casteara una propiedad `var`, una reasignación entre el chequeo y el uso aparecería como [`ClassCastException`]({{ "/es/glosario/class-cast-exception/" | relative_url }}) o [`NullPointerException`]({{ "/es/glosario/null-pointer-exception/" | relative_url }}) en [runtime]({{ "/es/glosario/runtime/" | relative_url }}). El sistema de tipos solo hace promesas que puede cumplir.
- **Snapshot en un `val`.** `val snapshot = cache` congela lo que leíste; cada uso posterior refiere al mismo objeto, así que el smart cast es correcto.
- **Menos `var`, menos bugs.** Cada `var` es un pedazo de estado que el lector tiene que seguir; preferí [`val`]({{ "/es/glosario/val/" | relative_url }}) más un valor nuevo (`copy`, `update { }`) antes que mutación in-place.
