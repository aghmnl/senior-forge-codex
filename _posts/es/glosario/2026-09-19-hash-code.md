## The Theory (El Qué)

**`hashCode`** devuelve el `Int` que usan las colecciones basadas en hash — `HashMap`, [`HashSet`]({{ "/es/glosario/hash-set/" | relative_url }}), `LinkedHashMap` — como índice de bucket para encontrar un objeto sin recorrerlo todo. Su contrato es una sola regla: si dos objetos son [`equals`]({{ "/es/glosario/equals/" | relative_url }}), tienen que devolver el mismo `hashCode`; al revés no hace falta (las colisiones son normales). Una data class ([Data Classes: copy, equals, toString]({{ "/es/01-kotlin-core/data-classes/" | relative_url }})) lo genera a partir de las propiedades del [constructor primario]({{ "/es/glosario/primary-constructor/" | relative_url }}), en conjunto con el `equals` generado, así que el contrato se cumple por construcción.

```kotlin
// Not found in FAS — standalone example
data class TaskId(val value: String)          // equals + hashCode se generan juntos

val seen = hashSetOf(TaskId("a"))
TaskId("a") in seen        // true: mismo hashCode → mismo bucket, y equals confirma

// A mano: los dos tienen que cambiar juntos, o el objeto se pierde en el set
class Broken(val id: String) {
    override fun equals(other: Any?) = other is Broken && other.id == id
    // sin override de hashCode → dos objetos iguales caen en buckets distintos
}
```

## The Senior Nuance (El Matiz Senior)

- **Romper el contrato pierde objetos, no lanza excepción.** Un objeto cuyo `hashCode` cambia después de insertarlo (una propiedad mutable dentro del hash) queda en el bucket viejo: `set.contains(x)` devuelve false para un `x` que el set contiene. El bug aparece lejos de la causa.
- **Las propiedades del cuerpo quedan excluidas.** Una data class con un `var timestamp` en el cuerpo hashea solo las propiedades del constructor — que es justamente lo que la hace segura como clave de map, y sorprendente si esperabas que el timestamp contara.
- **Solo propiedades estables e inmutables deberían entrar en un hash.** Esa es la razón práctica para declarar las propiedades de una data class como [`val`]({{ "/es/glosario/val/" | relative_url }}).
