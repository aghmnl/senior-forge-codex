## The Theory (El Qué)

**`combine`** es un operador intermedio de [`Flow`]({{ "/es/glosario/flow/" | relative_url }}) que fusiona varios flows en uno: cada vez que **cualquiera** de las fuentes emite, corre la transformación con el valor **más reciente** de cada una y emite el resultado. Espera a que todas las fuentes hayan producido al menos un valor antes de la primera emisión. Como todo operador intermedio es lazy — combinar flows no ejecuta nada hasta que se colecta el resultado.

```kotlin
// De FollowApp Suite — PremiumUseCases.kt
operator fun invoke(): Flow<Boolean> = combine(
    premiumLedgerRepository.getLedger(),
    authRepository.getSession()
) { ledger, session ->
    PremiumLifecycle.isPremium(now = System.currentTimeMillis(), premiumUntil = ledger.premiumUntil, isSignedIn = session != null)
}
```

## The Senior Nuance (El Matiz Senior)

- **`combine` es "lo último de cada uno", `zip` es "emparejarlos".** `zip` espera un valor de *cada* lado por emisión; `combine` re-emite ante cada cambio de cualquier lado. Usar `zip` para estado de UI congela la pantalla apenas una fuente deja de emitir.
- **Una fuente callada bloquea la primera emisión.** Si alguna entrada nunca emite, el flow combinado tampoco emite — causa habitual de una pantalla trabada en Loading. Dale a cada fuente un valor inicial.
- **Sigue siendo [cold]({{ "/es/glosario/cold-stream/" | relative_url }}).** Combinar tres flows y colectar dos veces corre los tres productores dos veces.
