## The Theory (El Qué)

**`first()`** es un [operador terminal]({{ "/es/glosario/terminal-operations/" | relative_url }}) que suspende hasta la primera emisión del flow, devuelve ese valor y **cancela el productor**. Convierte un stream en un valor único — una foto de una fuente viva — para que la [suspend function]({{ "/es/glosario/suspend-functions/" | relative_url }}) llamadora complete en vez de observar para siempre. `first { predicado }` espera el primer valor que cumpla la condición, y `firstOrNull()` devuelve `null` ante un flow vacío en lugar de lanzar `NoSuchElementException`.

```kotlin
// De FollowApp Suite — CleanUpPresetsUseCase.kt
// Lectura puntual de una fuente viva: tomar los presets actuales, actuar, terminar
suspend fun onLabelDeleted(labelName: String) {
    val presets = presetRepository.getAll().first()
    presets.forEach { preset -> /* ... */ }
}
```

## The Senior Nuance (El Matiz Senior)

- **Es la herramienta correcta para una foto y la incorrecta para observar.** Un `first()` donde querías [`collect`]({{ "/es/glosario/collect/" | relative_url }}) te da los datos correctos una vez y después queda obsoleto en silencio — sin error, sin log.
- **Sobre un flow vacío lanza excepción.** `first()` tira `NoSuchElementException` si el flow completa sin emitir; usá `firstOrNull()` cuando el vacío es legítimo.
- **Cancelar el productor es el punto.** Sobre un flow respaldado por [Room]({{ "/es/glosario/room/" | relative_url }}), `first()` lee una vez y desarma el observador en lugar de dejar una query viva.
