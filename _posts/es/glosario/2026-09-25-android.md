## The Theory (El Qué)

**Android** es el sistema operativo de Google para teléfonos, tablets, televisores, relojes y autos, construido sobre el kernel de Linux. Las apps se escriben principalmente en [Kotlin]({{ "/es/glosario/kotlin/" | relative_url }}), se compilan a bytecode DEX y corren sobre el [Android Runtime (ART)]({{ "/es/glosario/android-runtime/" | relative_url }}). La plataforma le da a cada app un proceso y un conjunto de componentes que administra el sistema (`Activity`, `Service`, [BroadcastReceiver]({{ "/es/glosario/broadcast-receiver/" | relative_url }}) y `ContentProvider`), cuyo [lifecycle]({{ "/es/glosario/lifecycle/" | relative_url }}) maneja el sistema, no la app.

```kotlin
// Not found in FAS — standalone example
// El sistema, no la app, decide cuándo corren estos callbacks
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)   // puede ser una recreación tras rotar
        setContent { App() }
    }
}
```

## The Senior Nuance (El Matiz Senior)

- **El sistema es dueño del lifecycle.** Una rotación destruye y recrea la `Activity`; la falta de memoria puede matar el proceso entero mientras la app está en background. Buena parte de la arquitectura Android (ViewModels, estado guardado, colección [lifecycle-aware]({{ "/es/glosario/lifecycle-aware/" | relative_url }})) existe para sobrevivir a decisiones que la app no toma.
- **Un único [main thread]({{ "/es/glosario/main-thread/" | relative_url }}) dibuja la UI.** Bloquearlo congela la pantalla y, después de unos segundos, produce un [ANR]({{ "/es/glosario/anr/" | relative_url }}). Esa restricción es la razón por la que las [coroutines]({{ "/es/glosario/coroutines/" | relative_url }}) y los dispatchers importan tanto en Android.
- **Los niveles de API son un contrato de compatibilidad.** `minSdk` decide qué dispositivos pueden instalar la app; `targetSdk` decide qué cambios de comportamiento le aplica el sistema. Subir `targetSdk` es una migración, no un cambio de número.
