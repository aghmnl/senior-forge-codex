## The Theory (El Qué)

**Fan-out** es cuando **varios consumidores leen del mismo [Channel]({{ "/es/glosario/channel/" | relative_url }})**, y los valores **se reparten entre ellos**: cada valor va a exactamente un consumidor, el que esté libre. Es la forma habitual de repartir trabajo entre una cantidad fija de workers. Lo opuesto, varios productores enviando a un mismo channel, se llama **fan-in**.

```kotlin
// Not found in FAS — standalone example
val jobs = Channel<File>(Channel.UNLIMITED)
files.forEach { jobs.send(it) }
jobs.close()

repeat(3) {                        // tres workers, una cola
    launch { for (file in jobs) upload(file) }
}
```

## The Senior Nuance (El Matiz Senior)

- **El fan-out limita la concurrencia gratis.** Con tres workers, como mucho corren tres subidas a la vez, sin importar cuántos archivos haya en la cola.
- **No es difusión.** Si cada consumidor tiene que ver cada valor, la herramienta es un [SharedFlow]({{ "/es/glosario/sharedflow/" | relative_url }}), no un channel.
