## The Theory (El Qué)

**`offer(value)`** es la forma vieja, hoy **deprecada**, de meter un valor en un [Channel]({{ "/es/glosario/channel/" | relative_url }}) sin suspender. Devolvía `true` o `false` según si el valor entraba, pero **lanzaba una excepción** cuando el channel estaba [cerrado]({{ "/es/glosario/close/" | relative_url }}), lo que lo hacía inseguro para llamarlo desde callbacks. Lo reemplazó [trySend]({{ "/es/glosario/try-send/" | relative_url }}), que informa todos los resultados, incluido un channel cerrado, en un [ChannelResult]({{ "/es/glosario/channel-result/" | relative_url }}) sin lanzar.

```kotlin
// Not found in FAS — standalone example
// Código viejo
if (!channel.offer(event)) Log.w(TAG, "Descartado")    // lanza si el channel está cerrado

// Reemplazo
channel.trySend(event).onFailure { Log.w(TAG, "Descartado") }   // nunca lanza
```

## The Senior Nuance (El Matiz Senior)

- **Aparece en código y respuestas viejas.** Reconocerlo importa al leer código legacy o ejemplos antiguos; el código nuevo usa `trySend`.
