## The Theory (El Qué)

**`produce { }`** es un builder de coroutines que crea un [Channel]({{ "/es/glosario/channel/" | relative_url }}), lanza una coroutine que lo llena con [send]({{ "/es/glosario/send/" | relative_url }}) y devuelve el lado que recibe (`ReceiveChannel`). Cuando la coroutine productora termina, falla o se cancela, el channel se **cierra automáticamente**, así que quien lo está leyendo con un `for` termina limpiamente. Está marcado como API experimental, pero es la forma idiomática de armar un productor.

```kotlin
// Not found in FAS — standalone example
fun CoroutineScope.numbers(): ReceiveChannel<Int> = produce {
    for (n in 1..3) send(n)
}                                  // el channel se cierra cuando termina el bloque

for (n in scope.numbers()) println(n)   // 1, 2, 3, y el ciclo termina
```

## The Senior Nuance (El Matiz Senior)

- **Elimina el bug más común de los channels.** Un channel creado a mano lo tiene que cerrar alguien, o sus receptores esperan para siempre. Con `produce`, el cierre queda atado a la coroutine productora y no se puede olvidar.
- **Vive en un scope.** `produce` es una extensión de `CoroutineScope`, así que cancelar ese scope cancela al productor y cierra el channel.
