## The Theory (El Qué)

**`send(value)`** mete un valor en un [Channel]({{ "/es/glosario/channel/" | relative_url }}). Es una [suspend function]({{ "/es/glosario/suspend-functions/" | relative_url }}): cuando el channel no tiene lugar (está lleno, o es un channel rendezvous sin buffer y nadie está recibiendo), `send` **suspende** hasta que un receptor toma un valor y hace lugar. Enviar a un channel que ya se [cerró]({{ "/es/glosario/close/" | relative_url }}) lanza una excepción.

```kotlin
// Not found in FAS — standalone example
val channel = Channel<Int>()       // rendezvous: sin buffer

launch { channel.send(1) }         // suspende acá hasta que alguien reciba
launch { println(channel.receive()) }   // toma el 1 y deja seguir a send
```

## The Senior Nuance (El Matiz Senior)

- **Suspender es la forma en que un channel aplica backpressure.** Un productor rápido espera a un consumidor lento en vez de llenar la memoria.
- **Desde código que no puede suspender, se usa [trySend]({{ "/es/glosario/try-send/" | relative_url }}).** Retorna de inmediato y dice si el valor fue aceptado.
- Ver [trySend() vs send()]({{ "/es/02-coroutines-flow/trysend-vs-send/" | relative_url }}).
