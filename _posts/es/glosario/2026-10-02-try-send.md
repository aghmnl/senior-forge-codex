## The Theory (El Qué)

**`trySend(value)`** es la forma **no suspendible** de meter un valor en un [Channel]({{ "/es/glosario/channel/" | relative_url }}). Nunca espera: si hay lugar, agrega el valor; si no, desiste. Devuelve un `ChannelResult` que dice si funcionó. Existe para el código que no puede llamar a una suspend function, como los [callbacks]({{ "/es/glosario/callbacks/" | relative_url }}) y los listeners, y es la forma en que se envían valores adentro de [callbackFlow]({{ "/es/glosario/callback-flow/" | relative_url }}). Su hermano suspendible es [send]({{ "/es/glosario/send/" | relative_url }}).

```kotlin
// Not found in FAS — standalone example
val events = Channel<Click>(Channel.BUFFERED)

button.setOnClickListener {
    val result = events.trySend(Click)
    if (result.isFailure) Log.w(TAG, "Click descartado: buffer lleno o channel cerrado")
}
```

## The Senior Nuance (El Matiz Senior)

- **Puede fallar, y la falla es silenciosa si no la revisás.** Con el buffer lleno, un channel rendezvous sin receptor, o un channel cerrado, el valor no se envía. Ignorar el resultado solo es seguro cuando perder un valor es aceptable.
- Es el equivalente para channels de [tryEmit]({{ "/es/glosario/try-emit/" | relative_url }}) en un `MutableSharedFlow`.
