## The Theory (El Qué)

**`remember { }`** guarda un valor en la [composition]({{ "/es/glosario/composition/" | relative_url }}) la primera vez que corre un composable y devuelve ese mismo valor en cada [recomposition]({{ "/es/glosario/recomposition/" | relative_url }}), en lugar de volver a calcularlo. Con keys, `remember(key1, key2) { }`, el valor se recalcula solo cuando cambia alguna de las keys.

```kotlin
// Not found in FAS — standalone example
val pending = remember(tasks) { tasks.filter { !it.isCompleted } }
```

## The Senior Nuance (El Matiz Senior)

- **Sobrevive a la [recomposition]({{ "/es/glosario/recomposition/" | relative_url }}), no a los cambios de configuración.** La rotación o la muerte del proceso lo borran; `rememberSaveable` es la versión que sobrevive a eso.
- **Las keys tienen que cubrir cada entrada.** Olvidarse de una significa usar un valor viejo cuando esa entrada cambia.
- **También preserva la identidad**, algo que importa para el [skipping]({{ "/es/glosario/skipping/" | relative_url }}): la misma lista recordada es la misma instancia en cada [recomposition]({{ "/es/glosario/recomposition/" | relative_url }}).
