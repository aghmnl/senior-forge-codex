## The Theory (El Qué)

**`mapSaver`** construye un [`Saver`]({{ "/es/glosario/saver/" | relative_url }}) que guarda un valor como un **mapa** de valores guardables con nombre. `save` devuelve el mapa, y `restore` lee cada campo por su clave.

```kotlin
// Not found in FAS — standalone example
val FilterSaver = mapSaver(
    save = { mapOf("query" to it.query, "onlyPending" to it.onlyPending) },
    restore = { Filter(it["query"] as String, it["onlyPending"] as Boolean) }
)
```

## The Senior Nuance (El Matiz Senior)

- **Las claves con nombre lo hacen robusto al reordenamiento** y más legible que [`listSaver`]({{ "/es/glosario/list-saver/" | relative_url }}) para clases con varios campos, a costa de los casts en `restore`.
