## The Theory (El Qué)

Un **`Saver<Original, Saveable>`** le dice a [`rememberSaveable`]({{ "/es/glosario/remember-saveable/" | relative_url }}) cómo guardar un tipo que un [`Bundle`]({{ "/es/glosario/bundle/" | relative_url }}) no puede contener. Tiene dos funciones: `save` convierte el valor en algo guardable ([primitivos]({{ "/es/glosario/primitives/" | relative_url }}), strings, listas de ellos), y `restore` reconstruye el valor a partir de eso. Se pasa como `saver`, o como `stateSaver` cuando el valor recordado es un [`MutableState`]({{ "/es/glosario/mutable-state/" | relative_url }}).

```kotlin
// Not found in FAS — standalone example
val ColorSaver = Saver<Color, Long>(
    save = { it.value.toLong() },
    restore = { Color(it.toULong()) }
)
```

## The Senior Nuance (El Matiz Senior)

- **Preferir [`@Parcelize`]({{ "/es/glosario/parcelize/" | relative_url }}) para clases propias** cuando la clase puede ser [`Parcelable`]({{ "/es/glosario/parcelable/" | relative_url }}); un `Saver` encaja con tipos que no controlás, como una clase de una librería.
- **[`listSaver`]({{ "/es/glosario/list-saver/" | relative_url }}) y [`mapSaver`]({{ "/es/glosario/map-saver/" | relative_url }})** son atajos para el caso común de partir un valor en varias partes guardables.
