## The Theory (El Qué)

**`Checkbox(checked, onCheckedChange)`** es el composable de casilla de verificación de Material. Como todo input de Material, es [stateless]({{ "/es/glosario/stateful-stateless/" | relative_url }}): dibuja `checked` e informa un toque con `onCheckedChange`, y quien lo llama decide el valor nuevo. Pasar `onCheckedChange = null` lo deja solo para mostrar, útil cuando el clic lo maneja toda la fila.

```kotlin
// Not found in FAS — standalone example
Checkbox(checked = task.isCompleted, onCheckedChange = { onToggle(task.id, it) })
```

## The Senior Nuance (El Matiz Senior)

- **Quien lo llama puede rechazar el cambio** simplemente no actualizando el estado, que es como encajan las validaciones o los diálogos de confirmación.
