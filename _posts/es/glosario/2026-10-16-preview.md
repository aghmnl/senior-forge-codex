## The Theory (El Qué)

Un **Preview** es un composable anotado con `@Preview` que Android Studio dibuja en el editor sin ejecutar la app. Muestra un componente con datos de ejemplo, y puede dibujar varias configuraciones a la vez (modo oscuro, tamaños de fuente, tamaños de pantalla).

```kotlin
// Not found in FAS — standalone example
@Preview
@Composable
fun RatingBarPreview() { RatingBar(rating = 3, onRatingChange = {}) }
```

## The Senior Nuance (El Matiz Senior)

- **Los composables [stateless]({{ "/es/glosario/stateful-stateless/" | relative_url }}) son triviales de previsualizar**: se pasan valores y [lambdas]({{ "/es/glosario/lambdas/" | relative_url }}) vacías. Un composable que necesita un [ViewModel]({{ "/es/glosario/viewmodel/" | relative_url }}) no se puede previsualizar sin construir uno, una señal fuerte de que debería recibir el estado.
- **Los Previews también son la base de los screenshot tests**, que detectan regresiones visuales automáticamente.
