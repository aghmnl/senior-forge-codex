# Senior Forge Codex: Study Log

> Tracks what is actually **studied** in each Gemini Notebook (not what is written) and keeps the evaluation debt visible.
> Article/notebook creation lives in `docs/TOPIC_TRACKER.md`; this file starts where that one ends.

## Rules (anti-procrastination)

1. **A notebook is not "studied" until its quiz is taken.** The quiz score is the minimum evidence of study.
2. **Eval debt** = notebooks created whose topic has no evaluation yet. It is recalculated every time this file is updated.
3. **Daily eval quota.** Articles keep their pace; on top of the day's article, at least **1 evaluation per day** while the debt is above 0 (2 per day while it is above 10). Fridays (catch-up day) target 3.
4. **Eval due date** = the date the notebook is added to this log + 7 days. A topic past its due date is **overdue** and goes first in the queue.
5. An evaluation is a session with Claude (cold, no notes) on the topic's Interview Prep Q&A plus follow-ups; the result (PASS / PARTIAL / FAIL) is recorded here and in `docs/TOPIC_TRACKER.md` (Last Eval / Eval Result), and in the weekly file under `evals/`.

## Notebook outputs

Every notebook generates the same set, consumed in this order:

| Key | Output | Settings |
| --- | ------ | -------- |
| A | Audio overview | — |
| S | Slide deck | — |
| V | Video overview | — |
| R | Report (study guide) | — |
| I | Infographic | Detailed |
| T | Data table | — |
| F | Flashcards | Standard count, medium difficulty |
| Q | Quiz | Standard count, medium difficulty — record score |

Cell values: :white_check_mark: consumed · :black_square_button: generated, not consumed yet · — not generated.
